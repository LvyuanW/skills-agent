模块以扁平的目录组织，每个子目录是一个独立的 skill（如 workspace、file-editing、feedback、images、background-tasks、code-repair、investigation、process-management、resource-management、acceptance-criteria），统一由三个层次构成：
- `SKILL.md`：YAML front-matter（`name`、`description`）加自然语言规范，定义何时选用该技能、调用约定、参数语义、错误处理和与其他技能的协作关系。
- `scripts/`：可选的 Python/shell 参考实现，供 Agent 通过绝对路径直接调用或按需改写；脚本之间不互相 import，仅按需要引用本技能内的其他脚本。
- `references/`：可选的扩展文档，用于补充示例、边界条件和跨轮次流程（如 incremental-editing、extraction、acceptance-checks、feedback-loop、across-turns）。

依赖方向是自上而下的文档互引：例如 feedback 引用 images、background-tasks、process-management；background-tasks 又引用 process-management；所有技能都通过 shell 工具调用外部命令，而不是被上层代码直接 import。模块本身不包含运行时入口，是纯声明 + 参考实现的“技能库”。
