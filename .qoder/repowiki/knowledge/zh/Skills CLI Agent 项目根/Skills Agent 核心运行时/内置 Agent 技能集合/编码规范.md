- 每个技能以 YAML front-matter 中的 `name` 和 `description` 元数据开头，随后用自然语言描述触发条件、调用约定、限制和与其他技能的协作。
- 辅助脚本放在技能目录下的 `scripts/` 中，并通过绝对路径在 shell 调用中引用，变量不会跨 shell 调用持久化。
- 复杂或易错的工作流将示例与约束拆到 `references/` 目录（如 incremental-editing、extraction、acceptance-checks、feedback-loop、across-turns），由 SKILL.md 中的链接引入。
- 对外部二进制（Chrome、PDF/Office 阅读器）采用惰性检测：先通过 probe_environment 检查可用能力，再执行实际工作，失败时返回明确诊断而非静默跳过。
- 对耗时或不确定终止的命令优先使用 background-tasks 的 `run_in_background=true` 并显式设置 `timeout_seconds`，避免让 shell 默认 120 秒超时掩盖长任务。
- 图片输出统一通过 `images` 参数声明宿主路径，并使用 `save_bounded` / `prepare` 确保编码后不超过 1 MB，超过则压缩或分格 compose。
