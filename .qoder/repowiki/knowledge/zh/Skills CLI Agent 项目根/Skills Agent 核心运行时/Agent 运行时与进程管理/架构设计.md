模块按职责分为四层：
- agent.py 的 `Agent` 类是入口，装配 `WorkingContext`、`Auxiliary`、`ToolRegistry`、`BackgroundResults`、`ProcessScope` 等组件，并通过 `_system()` 注入系统提示词与 background 协议。
- execution.py 提供前台命令的执行与清理：通过 `subprocess` + `os.killpg` 对进程组发送 SIGTERM/SIGKILL，并用 `ps` 探测子进程，失败时抛出 `ToolCleanupError` 阻止后续执行。
- processes.py 定义后台作业的持久化所有权（`ProcessScope`、`scope.json`、`runs/*.json`），校验严格格式并支持 job/service 两种生命周期；`observe_background_jobs` 读取元数据与 supervisor 身份以确认归属。
- background.py 的 `BackgroundResults` 将 session 历史中的 launch receipt 和 runtime_event 作为 outbox，在 Agent 同步边界上合并磁盘观测结果，向父会话交付已完成作业，并处理子会话移交（handoff）。
- terminal.py 基于 prompt_toolkit + rich 构建带 thinking block 的可交互终端视图，通过 `_display_only` 装饰器把 UI 更新调度到 UI 线程。
依赖方向单向：agent → (execution, background, processes, terminal)，background 仅反向依赖 processes 提供的 `observe_background_jobs`，terminal 不依赖其他模块。
