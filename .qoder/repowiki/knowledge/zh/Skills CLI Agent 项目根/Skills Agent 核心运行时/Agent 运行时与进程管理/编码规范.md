- 对外暴露的错误统一继承自 `ToolCleanupError`（或 `BackgroundJobError`），并在 `diagnostics` 字段中附带结构化诊断信息供上层消费。
- 后台作业的生命周期通过 `scope.json` + `runs/*.json` 文件描述，所有记录经 `_strict_registration` 进行强类型校验后再被观察。
- 异步 UI 更新通过 `_display_only` 装饰器检测当前线程，非 UI 线程时走 `DisplayQueue.post` 提交，避免跨线程访问 prompt_toolkit 对象。
- 需要证明所有权的标识符采用 `hashlib.sha56(...)` 派生（如 owner_session_id、job id、verification id），而非直接存储 PID 或路径。
- 超时参数统一经过 `validate_timeout` 校验，限制为有限正数且不超过 MAX_TIMEOUT_SECONDS，并以常量集中定义 DEFAULT/MAX/TIMEOUT 值。
