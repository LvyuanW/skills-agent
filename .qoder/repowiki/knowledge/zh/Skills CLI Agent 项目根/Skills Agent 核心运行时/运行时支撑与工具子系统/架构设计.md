本模块由一组相互独立、面向 Agent 运行期的工具子包构成，不定义对外 API 边界，而是被上层 `skills_agent` 包直接调用：
- `runtime.py`：通过 `add_agent_arguments` 注册 CLI 选项，并由 `create_agent` 组装 `Agent`、`SkillRegistry`、可选的 `DockerSandbox` 以及 LLM provider。
- `benchmark.py`：独立的 `python -m skills_agent.benchmark` 入口，复用 `runtime.add_agent_arguments` 与 `create_agent`，以隔离日志目录运行单任务。
- `environment.py`：在 Agent 创建时一次性抓取平台、shell、Git 仓库状态等不可变元信息，供提示词注入。
- `input.py` + `clipboard.py`：基于 prompt_toolkit 的 `KeyBindings` 实现 `c-v` 粘贴；macOS 下通过 `osascript` 调用 JavaScript for Automation 读取剪贴板文本、文件引用或 PNG 快照。
- `markdown.py`：基于 rich 的 `_Body`/`MarkdownStream` 提供带背景色的 Markdown 实时预览与终态输出。
- `images.py`：将消息中的 image block 投影为稳定的 `image_reference` URL（file/http/https），限制最多 10 张、单张 ≤1MB，并裁剪超出上限的图片。
- `feedback.py`：解析 shell 执行结果中的 `skills_agent_feedback` 信封或新的 `shell.images` 声明，校验路径/URL、识别 PNG/JPEG/GIF/WebP 头，并将附件持久化到 session。
依赖方向单向向外：本模块仅依赖同级包 (`agent`, `config`, `providers`, `sandbox`, `skills`, `session`, `cli`)，不被其他同层模块反向依赖。
