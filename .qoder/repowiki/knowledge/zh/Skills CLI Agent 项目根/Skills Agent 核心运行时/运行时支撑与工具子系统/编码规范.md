- 外部输入统一通过显式验证函数处理（如 `_image_path`、`_source_url`、`validate_images`），对空值、NUL、相对路径、非法 scheme 抛出 `ValueError`。
- 对外部命令（git、osascript）的调用采用 try/except 包裹并返回降级值（如 `unknown`、`false`），保证元数据收集失败不会阻止会话启动。
- 图片资源遵循固定约束：请求上限 `MAX_REQUEST_IMAGES = 10`、单图上限 `MAX_IMAGE_BYTES = 1_000_000`，并在越限时写入 `omitted_reason` 而非静默丢弃。
- CLI 扩展通过向已有 `ArgumentParser` 追加 `add_agent_arguments` 的方式复用公共参数，避免在每个入口重复定义。
- 富文本输出使用 rich 的 `Live` + `_Body` 模式：先以 transient live preview 逐块刷新，再在 `finish()` 中保留一份完整渲染。
