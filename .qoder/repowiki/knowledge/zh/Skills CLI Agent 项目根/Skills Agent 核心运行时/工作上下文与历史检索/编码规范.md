- 对外暴露的可调用对象通过类封装状态（如 `WorkingContext`、`Auxiliary`、`HistoryIndex`），并通过构造参数注入依赖（model/session/on_activity）。
- 可变输入在跨边界传递前统一使用 `copy.deepcopy` 剥离 `_raw`、`_anthropic_content`、`signature`、`encrypted_content` 等内部字段，避免污染上游。
- 工具调用与其全部结果被组织为不可分割的组：先扫描 assistant 消息中的 tool_call id 集合，再消费后续 role=tool 的记录直至集合清空，中途抛出错误表示孤儿或未完成。
- 需要持久化的状态文件采用临时后缀（`.tmp`）写入后再原子替换原路径，确保进程崩溃时不会留下半写文件。
- 面向 LLM 的提示文本以模块级字符串常量（如 `_SUMMARY`、`_REPORT`）集中声明，并在函数内通过 `_json`/`_text` 等辅助函数序列化消息体。
