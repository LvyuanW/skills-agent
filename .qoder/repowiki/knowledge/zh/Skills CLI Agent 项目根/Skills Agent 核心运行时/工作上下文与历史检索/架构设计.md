模块由四个职责分明的子包组成：
- `context/`：核心层。`__init__.py` 定义 `WorkingContext`，负责将主 Session 的原始消息投影为可保存的 `records`，按 assistant/tool-call/result 分组校验，处理中断调用恢复（`recover_interrupted_calls`）、图像投影、token 预算与磁盘序列化（`context.json`，原子写入 `.tmp` + replace）。
- `context/auxiliary.py`：独立的辅助模型调用层 `Auxiliary`，封装摘要生成与工具输出报告，通过 `_image_payload` / `_messages` 把图片/文件作为只读附件注入请求，并使用 `_groups` 保证工具调用与其结果不被拆分到不同压缩批次。
- `context/history.py`：独立于 WorkingContext 的历史索引器 `HistoryIndex`，读取同目录下的 `events.jsonl`，增量同步到 `history.sqlite`，使用 FTS5 虚拟表做 BM25 搜索，并以 Unicode 词元/CJK 双字切分构建索引。
- `context/history_skill/`：以 SKILL.md + scripts/history.py 形式暴露给 subagent 的历史检索技能，CLI 包装 `HistoryIndex.search/read/neighbors/list`。
- `sandbox/`、`session/`、`skills/`、`tools/`：当前仅保留空 `__init__.py`，作为预留命名空间，不携带运行时逻辑。
依赖方向单向向外：本模块依赖 `feedback`、`images`、`providers.*`、`session.Session`，不被同级其他业务模块反向依赖。
