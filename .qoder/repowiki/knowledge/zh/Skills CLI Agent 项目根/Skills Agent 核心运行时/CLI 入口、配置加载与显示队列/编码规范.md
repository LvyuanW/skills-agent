- 配置项集中声明于 DEFAULTS 字典与 CHOICES 枚举集合，所有值经同一 `_validate` 函数校验后再参与合并。
- 配置优先级采用多层 dict 展开：DEFAULTS ← 环境变量 ← TOML 文件 ← 显式 CLI 参数，最终包装成 argparse.Namespace 返回。
- 对外部输出对象采用鸭子类型探测（hasattr 检查 append_line / append_body / upsert_tool / complete_background_job 等），根据能力分支走富 UI 或纯文本路径。
- DisplayQueue 的生产者只持有极短临界区进行 append，渲染逻辑放在独立的 drain 循环中执行，避免阻塞上游。
- 相邻同类型的 text_delta / thinking_delta 事件通过 parts 列表聚合而非立即渲染，控制事件或回调构成合并边界。
