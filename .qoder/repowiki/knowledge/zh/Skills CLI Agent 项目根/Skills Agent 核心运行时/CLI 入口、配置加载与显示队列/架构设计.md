模块由四个职责清晰的文件组成，依赖方向单向：`__main__.py` 仅转发到 `cli.main` 作为可执行入口；`cli.py` 是交互主流程，负责 argparser 注册、会话运行、工具调用摘要与流式消息渲染（通过 `_print` / `_assistant_content` / `_tool_note` 等内部函数统一输出）；`config.py` 定义 DEFAULTS/CHOICES 白名单并实现 `load_agent_config`，按「显式 CLI > TOML > 环境变量 > 内置默认」优先级合并，再注入到 argparse Namespace；`display.py` 提供 `DisplayQueue`，在独立消费者线程中串行渲染，生产者仅加短锁入队，并通过事件类型匹配对连续 text_delta/thinking_delta 做增量拼接以避免 O(n²) 字符串拷贝。`cli.py` 通过鸭子类型检测输出对象是否具备 `append_line` / `append_body` / `upsert_tool` / `complete_background_job` 等接口以适配不同 UI 后端，不直接耦合具体渲染器。
