本模块以 `agent.py` 中的 Agent 主循环为中枢：启动时由 `cli.py` + `config.py` 解析 TOML/环境变量/CLI 参数组装运行配置，随后通过 `providers/` 下的 OpenAI/Anthropic HTTPProvider 适配层调用模型；模型返回的工具调用请求交由 `builtin_skills/` 中的 SKILL.md 声明与脚本实现处理，同时 `tools/`、`sandbox/`、`session/`、`skills/` 作为空包占位扩展点；执行结果经 `display.py` 的增量渲染队列刷新到 `terminal.py` 提供的 TUI，后台作业由 `background.py` + `processes.py` 管理进程组生命周期；`context/history_skill/` 提供基于 SQLite FTS 的长会话检索，`environment.py`、`clipboard.py`、`images.py`、`markdown.py`、`feedback.py` 等支撑文件统一向 Agent 暴露运行时能力。各子模块之间不直接互相 import，而是通过 Agent 实例与共享配置对象进行松耦合协作。
