tests/ 是一个扁平的 pytest 包，所有用例以 test_*.py 命名直接置于根目录，没有子包划分。
- 通用夹具与辅助：`background_jobs_fixture.py` 提供 `BackgroundJobsFixture`，通过内嵌 `ThreadingHTTPServer` + SSE 模拟后端，并调用 `skills_agent.processes.HELPER` 启动真实受管进程；`sse.py` 提供 `frame`、`responses_from_chat`、`stream_response` 将脚本化模型响应编码为 OpenAI / Anthropic / 内部三种 SSE 帧格式。
- 按子系统分文件组织：后台作业相关用例（test_background_*.py）、流式输出（test_stream_*.py、test_display_queue.py、test_terminal_view.py）、Provider 与重试（test_providers.py、test_provider_*.py）、工具与图像（test_tool_*.py、test_images_skill.py）、沙箱与进程（test_process_*.py、test_sandbox_timeout.py）、CLI/终端（test_cli_*.py、test_stop_*.py、test_*.terminal.py）等。
- 依赖方向单向：测试仅依赖被测模块（如 `skills_agent.*`）和自身夹具，不互相 import；跨用例共享状态通过临时 workspace 路径或 fixture 参数传递。
