本模块由三个协作子组件构成：
- `tb4_agents` 实现 Harbor Skills/Claude/Codex 三种原生 Agent 适配器，通过受控 Gateway 路由 DeepSeek 流量到不同后端。
- `tb4_control` 基于 Harbor 0.24.0 DockerEnvironment API 驱动环境构建、资源硬限制、磁盘准入、调度持久化与失败分类，并复用同一套 Harbor runtime（sitecustomize.py、runtime-bundle.sha256）执行探针任务。
- `assets` 提供跨子模块共享的运行时资产：Claude/Codex 的 agent.json、离线模型目录、能力探测脚本以及 `common/audit_proxy.py` 审计中继。
三者共同依赖 Harbor 0.24.0 的 DockerEnvironment 抽象；`tb4_control` 通过 `environment.py` 封装 Environment 生命周期，`tb4_agents` 通过 `gateway.py` 暴露统一入口，测试资产则被两者在 smoke/capability-preflight 阶段直接消费。
