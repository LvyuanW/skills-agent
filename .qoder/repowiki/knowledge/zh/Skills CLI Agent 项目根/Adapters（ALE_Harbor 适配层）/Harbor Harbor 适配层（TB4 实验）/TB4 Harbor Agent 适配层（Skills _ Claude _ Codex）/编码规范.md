- 所有外部 API 地址必须经 `gateway_base` 或 `audit_base` 规范化，禁止直接使用原始 URL 字符串。
- 对外部二进制与 tarball 采用固定版本常量加 SHA-256/SHA-512 校验后再上传到目标环境执行。
- 适配器在 `__init__` 中强制覆盖 `model_name`、`reasoning_effort`、`web_search` 等字段并拒绝未允许的变体。
- 失败摘要通过解析结构化事件日志提取有限字段，显式过滤掉 prompt/response/diagnostics 等敏感内容。
- 生命周期清理使用 shell trap EXIT/TERM/INT 确保子进程（benchmark、mcp_bridge）被 SIGTERM 后等待退出。
