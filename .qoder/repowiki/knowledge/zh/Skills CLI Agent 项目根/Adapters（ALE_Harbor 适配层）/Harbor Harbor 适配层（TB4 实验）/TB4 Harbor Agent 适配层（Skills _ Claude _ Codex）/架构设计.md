模块以三个并列的适配器为核心：`skills.py` 中的 `SkillsAgent` 继承 `BaseInstalledAgent`，在目标环境安装预打包 Python runtime 并启动 `skills_agent.benchmark`；`claude.py` 的 `DeepSeekClaude` 继承 Harbor 的 `ClaudeCode`，仅改写二进制路径、模型与审计基址；`codex.py` 的 `DeepSeekCodex` 继承 `Codex`，注入 Flash/max 专用模型目录与 CA bundle。三者共享 `gateway.py` 提供的 `gateway_base`/`audit_base` 白名单校验器，将入口 URL 规范化为 HTTPS + 授权主机 + `/v1` 后缀。`assets/skills/` 是随适配器一起部署的子进程资源：`mcp_bridge.py` 作为持久 MCP 代理暴露给 Agent shell tool，`sitecustomize.py` 注入审计钩子，`runtime-bundle.tar.gz` 及 `runtime-source.json` 描述可复现的 Python 3.12 运行时，`agent.json` 声明 `tb4_agents.skills:SkillsAgent` 供 Harbor 动态加载。依赖方向单向：适配器 → harbor.agents.installed.* 基类 → gateway 白名单 → assets 内自托管脚本。
