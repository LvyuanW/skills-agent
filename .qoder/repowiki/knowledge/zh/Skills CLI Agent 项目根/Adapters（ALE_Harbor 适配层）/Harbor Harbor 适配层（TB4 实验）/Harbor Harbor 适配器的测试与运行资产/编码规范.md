- 每个适配器的入口由 `agent.json` 声明 `import_path`、`model_name` 与 `kwargs`，凭据不写入文件而是通过环境变量注入。
- smoke 脚本使用 `http.server.BaseHTTPRequestHandler` 在内存中构造 SSE `response.created/output_item.added/completed` 事件流来模拟上游响应，避免真实 API 调用。
- 离线类 smoke 通过 `subprocess.run` 调用 `docker run`，将临时 fixture 目录挂载为只读 `/fixture`，从 `/runtime` 解压预构建的二进制并以 dummy 密钥运行。
- 对外部请求进行最小化元数据脱敏：仅收集 model、reasoning.effort、tools.name/type、input_tokens/output_tokens 等白名单字段，显式丢弃 raw headers、prompt、response text 与 provider error body。
- 测试报告统一序列化为 JSON 对象并写入 `/data/tb4/logs/<name>.json`，包含 `kind`、`passed`/`exit_code`、`request_metadata`、stdout/stderr 等稳定字段以便回放。
