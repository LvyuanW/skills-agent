本模块按适配器划分三个子目录：
- `codex/`：DeepSeek Codex 0.149.1 的预置配置，包含 `agent.json`（指向 `adapters.harbor.tb4_agents.codex:DeepSeekCodex`）、`smoke-agent.json`、`models.json`/`official-models.json`（实验过滤后的 Flash/max-only 目录与官方快照对比）、`catalog-source.json`、`certs/`（固定 SHA256 的 certifi 根证书），以及若干 smoke 脚本：`offline-image-smoke.py`、`offline-subagent-smoke.py`、`tls-auth-only-smoke.py`、`probe-responses.py`、`run-capability-preflight.py`，用于在 Docker 内拉起本地 mock HTTP server 并验证 CLI 的 exec_command/view_image/apply_patch、子代理路由、TLS 认证等行为；`capability-smoke-task/` 是一个独立的 task.toml + instruction.md + tests/Dockerfile 合成任务。
- `claude/`：Claude Code 2.1.300 的预置配置与离线协议冒烟脚本，同样通过 `agent.json` 暴露 `adapters.harbor.tb4_agents.claude:DeepSeekClaude`，并由 `live-capability-preflight.py`、`offline-protocol-smoke.py`、`offline-retry-smoke.py`、`setup-only-preflight.py`、`install-only.py` 驱动。
- `common/audit_proxy.py`：一个独立的可导入 Python 模块，实现基于 `http.server.ThreadingHTTPServer` 的轻量审计中继，白名单放行 `/v1/responses` 等端点，仅记录 model、effort、tools、usage 等允许字段，拒绝原始 prompt/response/body，供 smoke 流程临时桥接到上游网关。

依赖方向：所有 smoke 脚本最终通过 `subprocess` 调用 Docker 执行已预构建的 Codex/Claude 二进制，由 Harbor 控制层消费 `agent.json` 完成会话导出与 token 聚合；`audit_proxy.py` 直接 import `adapters.harbor.tb4_agents.gateway` 以复用授权网关白名单。
