adapters/ 作为顶层编排容器，横向并列两个互不依赖的子适配层：
- ale/skills_agent：面向 ALE 运行时，通过 AgentDeployer 协议把外部 LLM agent 包装成可部署的 skills agent。
- harbor/tb4_agents + harbor/tb4_control：面向 Harbor 框架，tb4_agents 提供 Claude/Codex/MCP 等具体 Agent 实现及 assets 下的离线模型、MCP 桥接与审计中继；tb4_control 提供预准备、能力探测、资源盘点与调度控制器，并通过 tb4_agents.gateways 与具体 agent 解耦。
两个子模块共享的横切关注点是：以 `agent.json` / `models.json` / `catalog-source.json` 等清单文件声明 agent 能力，通过 `assets/common/audit_proxy.py` 输出审计日志，并以 Dockerized smoke_task 目录结构承载离线验证任务。两者之间无直接 import，仅由上层 ALE/Harbor 启动器按运行时选择加载。
