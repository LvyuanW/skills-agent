模块由三部分组成：
- `skills_agent/`：作为独立 Python 包（`ale-skills-agent`），通过 hatchling 构建但 wheel 为空，实际代码由上层 ALE 安装；`deployer.py` 实现 `BaseAgentDeployer`，在 Linux sandbox 中以子进程方式启动 `skills_agent.benchmark` CLI，负责安装、launch、SIGTERM 清理以及将 `events.jsonl` 会话解析为 `TrajectoryBuilder` 轨迹。
- `config.py`：基于 dataclass 的 `SkillsAgentConfig`，校验 provider（openai/anthropic）、api_format、token_counter 等参数。
- `skills_agent.yaml` / `smoke.yaml`：ALE 运行时的部署描述与冒烟测试配置，通过 `${env:...}` 注入 model、package、API key 等环境变量。
- `patches/sandbox-cancellation.patch`：对 ALE 宿主沙箱执行器的补丁，引入 `_SandboxRun` token/cancel_marker/pid_file 机制，配合 launcher 脚本中的 `flock` 与取消标记文件，实现沙箱内进程的幂等终止与重试安全。
依赖方向单向：本模块仅依赖 `ale_run.base_interface` 的抽象，不反向引用 ALE 内部实现，补丁除外。
