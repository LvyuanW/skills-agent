根目录是项目的唯一发布单元：pyproject.toml 声明 entry point `skills-agent`（指向 `skills_agent.cli:main`），并以 `include = ["skills_agent*"]` 把 skills_agent_core、adapters、tests、docs 等子模块一并纳入同一个 setuptools 包；skills-agent.toml 提供全局配置入口（context/window/token 上限、可选 provider/model/base_url/skill_dirs/sandbox_image），被 core 与 adapters 共同消费。运行时以 core 为主循环，adapters 作为 LLM Agent 的适配层对外暴露 ALE/Harbor 两种部署形态，tests 覆盖各子系统行为，docs 提供提示词参考与 Terminal-Bench 4 评测任务清单，三者均依赖 core 提供的 Skill/Tool/BuiltinSkill 契约。
