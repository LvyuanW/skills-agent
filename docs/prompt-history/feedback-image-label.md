## v1 · 2026-10-11 · 新增

来源：当前工作区（未提交）。与[主工作提示词 v4](agent-system.md) 一同启用，现有 tools 不变。动态资料使用占位符，不保存实际任务或会话数据。

- 发现的问题：图片作为 shell 结果的一部分进入会话后，需要区分产物原路径与长期保存的观察快照，并保留用途标签。
- 本版本目标：在原生图片之前说明标签、实际源路径和会话快照路径，使模型能关联观察对象与保存的证据。
- 本版本效果：图片反馈与所属工具结果一同记录，原路径后续变化不会替换已保存的观察；报告和压缩仍能携带图片。标签本身不构成视觉内容判断。
